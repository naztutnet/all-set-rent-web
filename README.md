# ALL SET RENT — клиентский сайт

Отдельный адаптивный фронтенд для цифрового рентала оборудования съёмочным площадкам. Клиент получает один заказ, одну смету, одну доставку и одного ответственного исполнителя — независимо от того, с какого внутреннего склада собран комплект.

## Что реализовано

- выбор дат до просмотра каталога;
- каталог с фильтрами, поиском и доступными остатками;
- корзина и предварительная смета с пересчётом количества и срока;
- автоматические скидки для долгосрочной аренды;
- готовые комплекты под типовые задачи;
- интерактивный подбор оборудования по размеру и условиям смены;
- карта/СБП, безналичный расчёт и наличные как варианты оплаты;
- скачивание предварительной сметы;
- адаптивная версия и доступная клавиатурная навигация;
- подготовленная точка подключения к внутреннему backend «Бот-Склад».

## Локальный запуск

```bash
npm run dev
```

Сайт откроется по адресу `http://localhost:4173`.

## Проверка

```bash
npm test
npm run build
```

Сборка появится в `dist/`. Проект не требует внешних runtime-зависимостей.

## Структура

- `index.html` — семантическая разметка всех клиентских разделов;
- `styles.css` — дизайн-система и адаптивные стили;
- `src/app.js` — интерактивность каталога, подбора и сметы;
- `src/catalog.mjs` — данные каталога и расчёт аренды;
- `tests/` — тесты тарифной логики;
- `assets/` — локальные иллюстрации оборудования;
- `scripts/` — локальный сервер и воспроизводимая сборка.

## Подключение к Бот-Складу

Сейчас каталог работает на демонстрационных данных из `src/catalog.mjs`. Для промышленного подключения этот слой заменяется API-адаптером к Бот-Складу:

1. остатки и резервы по диапазону дат;
2. клиентские и партнёрские цены;
3. создание черновика единого заказа;
4. подтверждение сметы и способа оплаты;
5. статусы сборки, доставки, выдачи и возврата.

Интерфейс не показывает клиенту внутреннее происхождение позиции: распределение по собственному и партнёрским складам остаётся операционной логикой backend.
